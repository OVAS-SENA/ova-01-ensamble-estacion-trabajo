# OVA 01: Ensamble de una Estación de Trabajo de Alto Desempeño

Objeto Virtual de Aprendizaje interactivo desarrollado para la modernización de ambientes formativos del **SENA Centro Minero (Regional Boyacá)** - **Ambiente 205 (Sistemas y Redes)**.

## 🚀 Despliegue en Vivo
Accede a la versión interactiva web a través de GitHub Pages:
👉 **[https://ovas-sena.github.io/ova-01-ensamble-estacion-trabajo/](https://ovas-sena.github.io/ova-01-ensamble-estacion-trabajo/)**

## 🎯 Cobertura Curricular (OE2)
- **Tecnólogo en Sistemas Teleinformáticos (233108)**
- **Tecnólogo en Análisis y Desarrollo de Software - ADSO (228118)**

## 🛠️ Características del Recurso
- **Simulador Interactivo Isométrico 3D (SVG)** de ensamble de hardware (Socket AM5, CPU Ryzen 9 9900X, Cooler AIO 240mm, GPU RTX 5080).
- **Lista de Verificación UAT** para puesta en marcha y pruebas POST de taller.
- **Motor de Evaluación Gamificada** con retroalimentación automática y certificación descargable.
- **Cumplimiento Estándar SCORM 1.2** para integración LMS (Territorium / Moodle).
- Identidad visual institucional SENA (Verde institucional `#39A900`, tipografía accesible y soporte de modo oscuro/claro).
